# Deck Audience

Know the room before shaping the structure.

Dialog rules: `../new-deck/CONVENTIONS.md`. Principles: `deck-storyline`.

Input: `decks/<slug>/source/purpose.md`. The outcome there is the test for every answer here. Output: `decks/<slug>/source/audience.md`.

## Steps

1. **Profile the room.** Use the brief and `source/purpose.md` to describe the audience, decision power, current belief, likely objections, knowledge, stakes, and relationship with the presenter where relevant. Distinguish likely questions and assumptions from known facts; mark unavailable details `unknown`.
   - Completion: the available audience information and consequential assumptions are recorded.

2. **Objections.** For supplied or likely objections, record available answers and sources, or `gap`. Record `none` only when the brief establishes that none apply.
   - Completion: each recorded objection has an answer with a source, or a gap.

3. **Write the artifact.** Write `audience.md` with six sections: Group, Decision makers, Current belief, Objections, Knowledge and stakes, Relationship.
   - Completion: file written.

## Rules

- Keep answers about the audience. Slide ideas belong to deck-storyboard.
