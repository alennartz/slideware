# Deck Slide Rules

What each slide carries. Apply these to any slide, in a flow or an ad-hoc edit.

- **Content headlines state a claim.** "Churn fell after onboarding changed" is a headline. "Churn" is not. Title and divider slides may use a deck title or section label.
- **One idea per slide.** Split independent claims. A conjunction joining one comparison or relationship does not by itself require a split.
- **Lists: four or five bullets at most,** each one line where possible.
- **Body only what the headline needs.** Cut the rest.
- **Sources carry through unchanged** from the brief, existing deck, or `structure.md` when available. Mark a missing source for a factual claim `gap`; title and divider labels need no source. Ad-hoc edits need not create a structure artifact.
- **Visual: use the idea's visual, or `none`.** Do not decorate a slide that needs none. Diagrams and charts beat photos when the point is a number or a process.
- **Sections:** use a divider when it helps the audience navigate, not at every change of subject. A numbered divider can use `slide dark divider` with its number in `.kicker`.
- **Close:** end in a way that reinforces the outcome, following the selected class guide when applicable. Use a separate `slide dark closing` only when it serves the deck; the last content slide can be the close.
