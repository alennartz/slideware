# Class guide: celebrate

The audience must share a meaning: honour a person or thing, inspire, or mark an occasion. The talk praises or blames in the present. It promotes values the audience already shares. It does not argue a contested point.

Sources: Aristotle's epideictic (praise and blame in ceremonies, about virtue and honour). Perelman and Olbrechts-Tyteca: the speaker promotes shared values and avoids controversy.

## Sections, in order

Use `purpose.md`, `audience.md`, and the brief to draft; ask only if missing information blocks useful work. Record unavailable facts as `unknown` and missing evidence as `gap`.

1. **Subject.** Who or what is honoured, or what the occasion marks.
2. **Values.** The virtues or values the subject embodies that the audience can share. Express each as a claim sentence; include only values relevant to the meaning, not a quota.
3. **Particulars.** Moments or examples that show the values. Use available sources; mark unsupported factual examples as evidence gaps, and record `unknown` when an example is unavailable.
4. **Occasion.** Why this moment matters to the audience. If there is no particular occasion, record `not used`.

## Opening and close

Choose an opening suited to the audience and brief: the Subject, a particular, or the Occasion. Make the Subject clear, pair values with their particulars, and explain the Occasion where relevant. Close with the shared meaning the primary outcome names; a contested recommendation belongs in a persuade deck.

## Check the room

Use `audience.md` and the brief to assess how the audience feels about the subject. If they are hostile or sceptical, revisit deck-structure's class choice against the intended outcome; load another guide if the class changes. If their feeling is unavailable, record it as `unknown` rather than assuming agreement.
