# Class guide: review

The audience must learn from something that already happened. The review is forward-looking and assigns no blame.

Sources: the Army After Action Review, which compares intended and actual results and then asks what to sustain and improve. Aristotle's forensic genre judges past acts for accusation or defence, which is a different shape and not used here.

## Sections, in order

Use `purpose.md`, `audience.md`, and the brief to draft. Ask only if missing information blocks useful work; record unavailable facts as `unknown` and missing evidence as `gap`.

1. **Intended.** What the past activity was supposed to achieve. Use the original plan or target if available; `purpose.md` describes this presentation's outcome, not necessarily that historical target.
2. **Actual.** What happened, with its evidence or evidence gap.
3. **Result gap.** The difference between intended and actual, if known. Distinguish this result from an evidence entry marked `gap`; if either side is unknown, record the result gap as `unknown`.
4. **Why.** Causes of the observed result, including any result gap, in order of importance, each a claim sentence. Distinguish evidenced causes from hypotheses and mark missing evidence as `gap`. If causes are unknown, record `unknown`; if no causal explanation applies, record `not used`.
5. **Sustain.** What to keep doing, and the evidence that it worked or its evidence gap. Record `not used` if there is nothing to sustain.
6. **Improve.** What to change next time, tied to a cause in Why; mark changes based on hypotheses as tentative. If no cause is known, record an investigation or `unknown` rather than inventing a fix. Record `not used` if no improvement applies.

## Opening and close

Choose an opening suited to the audience and brief: Intended and Actual, or the Result gap if known. Establish the intended and actual results before explaining causes. Close with applicable sustain and improve actions, tied to the learning outcome in `purpose.md`.
