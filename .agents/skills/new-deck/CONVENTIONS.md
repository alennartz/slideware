# Deck Dialog Conventions

Every deck step follows these rules.

- Use the brief and existing artifacts first. Make reasonable choices for the deck, record consequential assumptions, and proceed without approval of intermediate work. Follow the user's requested level of collaboration.
- Ask only when missing information or a consequential choice blocks useful work, or when consent is required. Group related missing information; use `ask_user` for a choice among options.
- Keep artifacts consistent when later work changes them. Report consequential assumptions, unresolved gaps, and the final deck's status to the user.
- Write claims in the audience's terms: what the audience will do or believe, not what the presenter shows.
- Mark unavailable facts `unknown` and missing evidence `gap`; distinguish assumptions from facts. Never invent facts, sources, or user acceptance of a gap.
